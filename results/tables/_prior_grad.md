# 物理先验"生效却有害"的解析式机制诊断（零训练）

口径：`L_freq` 中 softmax 只在**有理论频率的类**上归一化（`fault_only=True`），与训练时一致；`rel` 与损失逐字同口径（最小峰 / 最小谐波 / 按基频归一）。
梯度为闭式解 `dL_freq/dlogit_c = p_c (rel_c - rbar)`，因此这里算的是**最优 epoch 处真实的反传信号**，不是近似。
统计仅覆盖真类 ∈ 故障类（NC 无理论频率）的 query 样本；转速 1797 rpm。

格子的含义：`M+` = 模型判决正确，`M-` = 错误；`P+` / `P-` = 物理规则对/错。
`净替换` = (物理能救回的样本数 − 物理会弄坏的样本数) / 样本数。

- `净替换 <= 0` ⇒ 把判决完全交给先验都不赚，优化器朝它走只会更差。
