# INT8 动态量化实测（PyTorch CPU，非目标硬件）

量化：`torch.ao.quantization.quantize_dynamic(Linear/Conv1d -> qint8)`；BN 与激活保持 FP32。
FP32 与 INT8 使用**同一 seed 重建的同一组 episode**，逐 episode 可比；n=8 seeds，checkpoint 取自 `b_3c_s12_sh5_s8/*/best.pt`。
延迟为本机 CPU **单线程**、batch=64 窗的中位耗时，**不代表 ESP32-S3 实测**，仅反映同一后端下 INT8 相对 FP32 的量级变化。
